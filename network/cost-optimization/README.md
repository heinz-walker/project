## 흐름
방화벽 표준화로 늘어난 네트워크 비용을 "공식 단가 확인 → 실측 사용량 조회 → 비용 추정 → 절감 여지 판단" 순서로 분석하는 프로젝트다.
각 문서는 독립된 리포트이고, 비용 항목이 추가될 때마다 번호를 이어 붙인다.

1. **[Network Firewall·NAT Gateway 비용 구조 분석](./01-nat-firewall-cost-structure.md)** — NAT 요금 면제 조건을 실제 라우팅으로 검증하고, 사용량 실측으로 비용의 약 87%가 방화벽 엔드포인트 고정 시간당 요금임을 확인했다.
2. **[Dev 방화벽 운영 방식별 비용 시나리오](./02-dev-firewall-cost-scenarios.md)** — 1번 결과를 바탕으로 상시 트래픽이 필요 없는 Dev 방화벽의 운영 방식별 순절감(상시 off 약 85%, 업무시간만 on 약 60%)을 계산했다.
