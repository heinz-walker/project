1. 사회공학 (Social Engineering) 간단 보안지식
기술보다 사람을 노리는 해킹
미완료
▼
사회공학이란?

사람의 심리(신뢰, 공포, 호기심 등)를 이용해 정보를 훔치는 공격 기법입니다. 보안 시스템이 강력해도 휴먼에러는 발생할 수 있기에 가장 경계해야 합니다.

😵 휴먼에러: 긴급 상황이나 권위자의 지시로 위장해 판단력을 흐리게 만듭니다. (예: "CEO 긴급 지시", "계정 잠금 알림")
🧠 공격자가 노리는 심리 포인트
⏰
긴급성 Urgency
설명: 시간 압박으로 판단 시간을 빼앗습니다.
예시: "10분 내 인증 안 하면 잠금", "지금 승인하지 않으면 비활성화"
🏢
권위 Authority
설명: 상급자·기관 로고로 신뢰를 가장합니다.
예시: "보안팀 공지: VPN 갱신 필수", "임원 지시: 즉시 확인"
🎁
호의·보상 Reward
설명: 선물·쿠폰·도움 요청으로 호의를 유도합니다.
예시: "설문 쿠폰 지급, 여기서 로그인", "검증 부탁 링크"
🔍
호기심 Curiosity
설명: 궁금증을 자극해 열어보게 만듭니다.
예시: "급여명세 확인", "연말정산 환급 안내.pdf", "회의 녹화본"
⚠️
두려움 Fear
설명: 벌금·고발·계정 제한으로 불안을 조성합니다.
예시: "미납 벌금, 오늘 미납 시 고발", "보안 미준수로 계정 잠금 예정"
🔁
일관성·신뢰 Consistency/Trust
설명: 기존 스레드·내부 용어로 ‘원래 업무’처럼 위장합니다.
예시: 기존 프로젝트 메일에 "추가 파일 확인" 링크 삽입
👥
사회적 증거 Social Proof
설명: 모두가 따르는 것처럼 보여 따라 하게 만듭니다.
예시: "R&D팀 완료, 미완료 시 제한", "전사 필수 교육 링크"

3. 매체 제어
USB, 이동식 저장매체 차단 정책
미완료
▼
  • 사내 보안 정책상 USB 등 이동식 저장매체는 기본 차단입니다.
  • 필요 시 [전자결재 → 매체 사용 신청] 후 [DLP 승인] 과정을 거쳐야 합니다.
  • 매체 사용 기한은 개발자만 1년이고 그 외 임직원분들은 6개월이 최대 기한입니다.
⚠️ 전자결재가 완료되어도 매체별로 또 엔드포인트 보안 솔루션(DLP)으로 승인을 요청주셔야합니다!
예) USB 사용 결재를 신청해도, 엔드포인트 보안 솔루션으로 USB 별로 승인 허용이 필요
매체 정책 설명
이동식 디스크 차단(기본) USB 등 이동식 저장매체
CD-ROM/DVD/BD 차단(기본) 광학 매체
휴대용 디바이스 차단(기본) 스마트폰·태블릿·외장 HDD 등
이미지 캡처 디바이스 차단(기본) 카메라·웹캠·스캐너 등
Wireless LAN 허용(파일 반출 기록) 무선랜 사용 시 파일 반출 기록
Bluetooth 허용(파일 반출 기록) 블루투스 데이터 전송 시 기록
USB 테더링 허용(파일 반출 기록) USB 테더링 이용 시 파일 반출 기록
💡 승인 Tip: 결재 상신 후 보안팀에 DM 주시면 빠르게 처리됩니다.
OX 미니 테스트
1) 매체제어는 단순 전자결재만 받으면 사용할 수 있다.
2) 매체 사용 기한은 개발자만 1년이고 그 외 임직원분들은 6개월이 최대 기한이다.
3) 웹캠(이미지 캡처 디바이스)를 사용하기 위해 전자결재를 상신했고, 승인이 완료된 상태이다. 그리고 노트북의 "웹캠을 엔드포인트 보안 솔루션에 사용신청"했다면 회의실에서 웹캠이 사용가능하다.

4. 임직원 보안점검
CLEAN PC / CLEAN DESK
미완료
▼
업무환경 점검은 정보보안 활동의 기본입니다.
자리·장비·계정·매체 상태를 정기적으로 정돈하고 확인하는 습관이 보안 사고를 막는 첫걸음입니다.
🗂️
임직원 보안점검 (분기별)
CLEAN PC · CLEAN DESK 상태를 정기적으로 확인해 잠금·업데이트·백신, 책상 정리, 매체·계정 보안 개선점을 안내합니다.
🪑
내 자리
책상·서랍 정리, 출력물/포스트잇 확인
💻
내 PC
잠금·백신·업데이트·화면보호기 설정
🗄️
담당 서버·자산
접근권한·패치 상태·물리/계정 보안 점검
CLEAN PC (임직원 PC 보안점검)
당사는 엔드포인트 보안 솔루션(DLP·PC 보안점검 통합)을 통해 임직원 PC 보안점검을 하고 있습니다.
분기 점검·결재가 이 솔루션으로 연동되어 점검 이력과 개선 사항을 추적합니다.
🖥️ PC 보안점검 대시보드
(취약 항목 수 · 조치 필요 목록 · 조치하기 버튼)
PC 보안점검 방법
보안 솔루션 실행 ➜ 홈 메뉴 ‘자세히 보기’ 클릭 ➜ 조치 필요 항목 ‘조치하기’ 후 안내 진행
🔒
CLEAN PC 체크리스트
1.윈도우 업데이트 적용 여부 확인
2.바이러스 백신 설치 및 최신 업데이트
3.화면 보호기 사용(20분) + 재시작 시 로그온 화면 표시
4.공유 폴더 해제
5.USB 자동 실행 해제
6.안전한 PC 비밀번호 사용
7.PC 비밀번호 180일 주기 변경
CLEAN DESK (업무환경 보안점검)
우리 회사는 정보보안팀의 직접 순찰을 통해 임직원 업무환경 보안점검을 실시하고 있습니다.
정보보안팀이 점검 기간 동안 상시 순찰을 진행합니다.
🧹
CLEAN DESK 체크리스트
1.개인 책상·휴지통·회의실·복합기 주변에 계정 정보가 포함된 출력물 방치 여부 확인
2.휴대용 저장장치 방치 여부 확인
3.회의실 노트북에 브라우저(사내 계정) 및 사내용 메신저(Slack) 로그인 여부 확인
4.회의실 노트북에 개인/민감 정보 파일 존재 여부 확인
5.비인가 AP(공유기) 기기 존재 여부 확인
6.프린터 기기에 개인정보 포함 문서 방치 여부 확인

당사 공식 Wi-Fi는 두 개입니다.

Corp-Office
업무용 (보안팀 모니터링)
비번은 3개월 주기 변경 (Notice 공지)
Corp-Guest
게스트/개인용
사내 내부망 접근 불가
비밀번호 확인: 사내 포털 → 정보보안팀 가이드
공용망 주의
카페/지하철 Free Wi-Fi는 VPN 없이 접속 금지, 민감 업무는 사내망만 사용.
SSID 확인
무단 AP에 접속하지 않도록 SSID/패스워드 공지 확인 후 접속.
테더링
외부 장소에서 불가피할 땐 휴대폰 테더링 + VPN 사용으로 보호.
📶 Wi-Fi 보안 OX 퀴즈
1) 회사에서 잡히는 타 회사의 Wi-Fi를 몰래 사용하면 된다. (O/X)
2) 공용 Wi-Fi에서는 VPN을 켜고 민감 업무를 최소화해야 한다. (O/X)
3) 사내 업무는 반드시 Corp-Office에 접속해 진행해야 한다. (O/X)
